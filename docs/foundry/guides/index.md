# Guides

The end-to-end walkthrough of the full Temporal stack, and how to make the template your
own.

The three end-to-end guides are meant to be read in order — each picks up where the last
one left off.

- **[End-to-End: Getting Started](./end-to-end-how-to-getting-started.md)** — stand up the
  whole stack from scratch: Temporal Server, the workflow worker, the workflow API, and a
  mock agent
- **[End-to-End: Next Steps](./end-to-end-how-to-next-steps.md)** — swap the mock agent for
  a real, Bedrock-backed [Strands Base Agent](https://github.com/boozallen/strands-base-agent/blob/HEAD/docs/foundry/index.md)
- **[End-to-End: Advanced](./end-to-end-how-to-advanced.md)** — replace the linear 3-step
  workflow with a multi-phase, loop-based one using human-in-the-loop feedback cycles
- **[Customization Guide](./customization-guide.md)** — replace the template workflows,
  activities, and data models with your business logic
